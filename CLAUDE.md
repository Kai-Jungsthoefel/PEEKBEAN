# CLAUDE.md

Peekbean: a static website that shows almost any file format entirely in the browser, and converts many of them. No backend, no uploads, no network requests. See `README.md` for the format list and details.

## Commands

```sh
npm run dev        # Vite dev server
npm run build      # tsc --noEmit + production build + license allowlist check (this is what CI runs)
npm run typecheck  # types only
npm run samples    # regenerate samples/ from scripts/generate-*-samples.mjs
```

There is no test suite. Verify with `npm run build` and by opening the matching files from `samples/` in the browser (desktop and phone width).

## Layout

- `src/core/registry.ts`: all viewers and the format detection (signature, then extension, then text sniffing)
- `src/viewers/<id>.ts` (+ folder for larger ones): one lazily loaded module per viewer, `mount(ctx)` → `{ destroy() }`, types in `src/core/types.ts`
- `src/workers/`: heavy parsing and decoding in web workers
- `src/metadata/`: readers for the info panel, loaded only when it opens
- `src/convert/`: the converter. `catalog.ts` lists what converts into what (plain data, the build also reads it), `converters/<id>.ts` reuse the viewers' readers, `page.ts` is `convert.html`; `vite.config.ts` writes one page per conversion (`jpg-to-png.html` …); conversions from a `minor` source to a `minor` target get `noindex`. The viewer's "Export" (`src/export-dialog.ts`) runs the same modules
- `src/format-pages.ts`: the viewer's pages per format (`dwg-viewer.html` …) with their own texts, `src/prerender.ts` their HTML for search engines. A format gets a page only with text of its own and real searches for it; near-identical pages count as doorway pages
- `src/site.ts`: header parts, footer and file drop shared by the viewer and the converter
- `src/wasm/`: prebuilt WebAssembly (checked in). Sources: `crates/dwg2dxf` (Rust, acadrust) and `wasm/libarchive` (Emscripten); rebuild only via `npm run build:*-wasm`
- Word and PowerPoint render through the separate MIT library [ooxml-pages](https://github.com/Kai-Jungsthoefel/ooxml-pages) from npm; rendering bugs get fixed there, not patched here

## Rules

- **Privacy first.** Nothing leaves the browser. No CDNs, no remote fonts, no telemetry; every asset ships with the site. The CSP in `vite.config.ts` allows only `'self'` and no `unsafe-eval`; don't loosen it.
- **License: GPL-3.0-or-later.** New dependencies must pass `ALLOWED_LICENSES` in `vite.config.ts` (MIT/BSD/Apache/MPL/LGPL/GPL-3.0 are fine; proprietary, non-commercial, GPL-2.0-only and SSPL are not). License texts of native code inside WASM go into the extra list there / `licenses/`. Every source file starts with `// SPDX-License-Identifier: GPL-3.0-or-later`.
- **UI is English only**, numbers and dates formatted with `en-US`. This includes errors, progress messages and warnings from the Rust crate.
- **The repo is public.** Never commit company names, real documents or paths from work machines. Real test files go in `samples/private/` (gitignored) or stay where they are. Samples in `samples/` are generated by scripts and CC0; check their embedded metadata (docProps, PDF info, DWG author) too.
- Commit with the repo-local GitHub noreply identity (check `git config user.email` first).
- Style: strict TypeScript, no framework, DOM built via `h()` from `src/core/dom.ts`; keep comments in the same short explanatory style as the surrounding code.
- `TODO.md` is the owner's German task list (gitignored). Notes from Claude go in parentheses under the item, in German.
